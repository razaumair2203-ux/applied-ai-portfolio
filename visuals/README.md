# Visual evidence provenance

The images in this directory are **evidence composites**, not generated illustrations.

## Reality guardrail

Permitted transformations are limited to:

- crop and resize;
- conservative exposure / contrast / sharpness adjustment where useful;
- deterministic panel composition;
- arrows, boxes, headings, labels and captions;
- web compression.

The portfolio does **not** use generative image synthesis, object insertion/removal, fabricated detections, invented UI states, invented metrics, or synthetic replacement backgrounds.

## Why composites are used

A hiring reviewer needs to distinguish **field evidence, product implementation and evaluation depth** quickly. The composites therefore improve visual hierarchy while preserving the original evidence. For technical verification, each project page links to code, measured artefacts, public repositories or dataset records where disclosure permits.
