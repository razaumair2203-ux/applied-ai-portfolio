# Original engineering media — real hardware, trials and research

The four lead boards below were assembled **only from original project photographs and recorded experimental image files**. The editing process performs layout, source-image cropping, scale and captioning—not image generation, restoration, inserted objects or recreated hardware. Every original source is linked.
